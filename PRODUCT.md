# Product

## Register

product

## Users

One person manages personal mail across several accounts and domains.
The primary devices are a Mac running macOS and an iPhone.
Desktop use favors keyboard control. iPhone use supports the same core tasks
through touch. Compact density is the default; comfortable density is optional.

## Product purpose

Read, search, organize, and send mail from one dependable application.
Core mail works without classification or any model service.
`SPEC.md` defines behavior, storage, and acceptance requirements.

## Brand personality

Minimal, modern, responsive. The interface feels calm and carefully finished.
Small interactions provide clear feedback and make repeated tasks feel effortless.

## Design references

The user selected these references:

- Linear: visual restraint and consistent controls.
- Raycast: the command palette and keyboard navigation.
- Superhuman: fast mail triage and keyboard workflows.

Use these qualities to guide the design. Keep the product's own components
and interaction rules consistent across desktop and phone.

## Anti-references

Avoid competing colored badges, moving backgrounds, and translucent reading surfaces.
Avoid hidden commands that require memorization. These constraints follow the
local email research report and the user's request for a minimal interface.

## Design principles

- Keep message content central and actions easy to find.
- Use one component vocabulary across all views.
- Give immediate feedback while showing the true synchronization state.
- Make keyboard commands discoverable through the command palette.
- Include purposeful microinteractions in the MVP.

## Accessibility and inclusion

Follow the local report's accessibility release gate. Support keyboard use,
screen readers, visible focus, reduced motion, and zoom without lost controls.
Never use color alone to communicate state. `SPEC.md` defines measurable checks.
